# 공구불출관리포털 (데모)

`index.html` 파일 하나로 동작하는 **부서 신청 · 관리자 불출 · 재고/대여 현황** 웹앱입니다.
CDN·웹폰트·외부 라이브러리를 쓰지 않아 인터넷 없이도 파일만 열면 그대로 동작합니다.

- 데모 주소: https://koreatoolroom.github.io/
- 데이터는 각 브라우저의 `localStorage`에만 저장됩니다(서버·DB 없음). 상단 **[데모 데이터 초기화]** 로 처음 상태로 되돌릴 수 있습니다.
- 여러 부서가 실시간으로 함께 쓰려면 서버(또는 무료 DB)를 붙여야 합니다. `index.html` 안의 `API_BASE` 값과 `CONFIG` 설정은 파일 안 주석을 참고하세요.

## 화면

| 탭 | 하는 일 |
|---|---|
| 부서 신청 | 부서 선택 → 품목 검색·공구/자재 필터 → 담기 → 수량·용도 입력 → 신청 |
| 관리자 불출 | 대기/불출완료/반납완료/반려 목록 확인, 승인·반납완료·반려 처리 |
| 재고·대여 현황 | 공구 대여 현황, 자재 재고·부족 경고, 품목 추가·수정, CSV 내보내기, 인쇄 |

자재는 불출 승인 시 재고가 차감되고, 공구는 승인 시 대여중으로 바뀌었다가 반납완료 시 다시 대여 가능해집니다.

## 설정

`index.html`의 `<script>` 안 `CONFIG`만 고치면 됩니다.

- `appTitle` : 앱 제목
- `unitName` : 상단 제목 아래 표시 문구
- `departments` : 부서 목록
- `items` : 초기 품목 (`kind:'tool'` 공구 / `kind:'material'` 자재, `qty`, `min`)
